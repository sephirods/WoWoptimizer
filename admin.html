¿Cómo funciona el sistema de datos?

El optimizador cuenta con datasets base estáticos (archon_data.js, wow_stat_priorities.js, wowhead_data.js, bloodmallet_data.js) embebidos en el código.

Cuando ejecutas los scripts de extracción y subes los archivos actualizados en este panel, se almacenan en el almacenamiento local persistente y toman prioridad inmediata en toda la aplicación sin requerir desplegar el servidor.

Si alguna vez deseas volver a los valores estándar, cada módulo cuenta con un botón de "Restaurar Original".

Presets de Archon.gg

archon_data.js
Por Defecto Contiene los objetivos meta para Mítica+ y Banda de las 39 especializaciones.

Instrucciones de Extracción:

  1. Abre archon.gg/wow en tu navegador.
  2. Abre las herramientas de desarrollador presionando F12 y selecciona la pestaña Console.
  3. Pulsa "Copiar Script" arriba, pégalo en la consola y presiona Enter.
  4. El script escaneará automáticamente y descargará el archivo archon_data.js.
  5. Sube el archivo aquí con el botón "Subir archon_data.js" para activar los nuevos datos en el optimizador.
